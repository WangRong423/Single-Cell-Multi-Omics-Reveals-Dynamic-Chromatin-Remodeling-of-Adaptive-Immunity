# Single-Cell-Multi-Omics-Reveals-Dynamic-Chromatin-Remodeling-of-Adaptive-Immunity
This repository contains code supporting the study **"Inactivated prime-boost vaccination induced dynamic trained immunity modulated by epigenetic remodeling in monocytes"**

## Overview

Vaccination induces durable adaptive immunity, yet how transcriptional and chromatin programs are dynamically established and reorganized across successive vaccine doses remains poorly understood. Here, we performed paired single-nucleus RNA sequencing and chromatin accessibility profiling of peripheral blood mononuclear cells collected from four individuals at ten time points spanning primary and booster immunization with the inactivated SARS-CoV-2 vaccine BBIBP-CorV
